PathoCore

An open-source ecosystem for pathogen genomic surveillance and research data sharing. It connects metadata standardisation, bioinformatics processing and controlled data access through a single versioned data model — a JSON Schema and a laboratory template, generated together — so that a laboratory network can validate, analyse, store and share its data without building any of it twice.
